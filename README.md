# MERN Stack Authentication Project

A simple MERN Stack Authentication Project with:

- User Signup
- User Login
- Protected Home Page
- MongoDB Database Integration
- React Frontend
- Express & Node.js Backend

---

# Features

## Authentication System
- User Registration
- User Login
- Logout Functionality
- Local Storage Authentication

## Frontend
- React.js
- React Router DOM
- Responsive UI
- Protected Routes

## Backend
- Express.js REST APIs
- MongoDB Database
- Mongoose Models
- CORS Enabled
- JSON Data Handling

---

# Technologies Used

## Frontend
- React.js
- React Router DOM
- CSS

## Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- CORS
